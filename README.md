Клиентский мод для Minecraft Java **1.21.11**, Fabric Loader **0.19.3+**, Java **21**.
Репозиторий исторически называется `VisionMod-1.0.0`; версия сборки — `2.0.0`.

- **Right Shift** — меню с поиском, категориями и настройками по ПКМ. СКМ назначает горячую клавишу доступным модулям.
- **Визуал → Скрыть ники и бирки** — скрывает подписи над игроками и именованными мобами в мире. Карточку также можно найти по слову «бирки».
- Повторное открытие меню возвращает прежний раздел, страницу, поиск и редактор в текущем запуске Minecraft. Right Shift также закрывает его в игру; Escape в редакторе возвращает назад.
- **Fast Scroller** в УТИЛИТАХ: Shift + колесо над слотом или Shift + ЛКМ с проведением по слотам для переноса стаков между обычным инвентарём и контейнером.
- **End** — глобальное отключение; FPS Boost возвращает сохранённые видеонастройки.
- **Left Alt** — Free Look на время удержания. **C** — Zoom (назначения можно изменить).
- **Внешний вид → Плавный хотбар** — движение выделения и акцент иконки; выбор предмета остаётся мгновенным.
- **T / чат** — перетаскивание HUD левой кнопкой; правая кнопка возвращает позицию.

## World Lyrics — только мод

Включи **МИР → World Lyrics**, затем запусти музыку. Расширение браузера, ключ сопряжения и локальный сервер больше не нужны. Старое расширение можно удалить.

При наличии таймкодов строки следуют позиции песни, паузе, перемотке и скорости воспроизведения; пустые интервалы не подменяются собственными строками. Поиск проверяет название, исполнителя и известную длительность версии, поддерживает совместных исполнителей и убирает служебные суффиксы плеера.

Мод получает название, исполнителя, паузу и позицию из системной медиасессии:

- Windows 10/11 — Windows Media Control через встроенный Windows PowerShell. Один фоновый процесс только на время работы функции.
- Linux — MPRIS через системный `gdbus`, в пользовательской D-Bus-сессии. `gdbus` обычно входит в GLib рабочего стола.
- macOS — автоматическое чтение пока не поддерживается; остаются локальный LRC и свои строки.

Браузер/плеер должен публиковать системные медиаданные. Если он их не отдаёт, название и позиция не могут быть получены этим способом. В **ПКМ → Настроить** виден статус.

Текст запрашивается асинхронно из LRCLIB, Яндекс Музыки при подключённом доступе и запасного `lyrics.ovh`. Поиск пробует точный запрос и несколько вариантов поиска. Реальные таймкоды имеют приоритет; обычный текст сохраняется, а его строки листаются стрелками в настройках World Lyrics. Без позиции плеера точная синхронизация также недоступна — статус объясняет причину. Название песни больше не подставляется вместо слов.

Если автоматический поиск пропустил песню, скопируй её текст и открой **World Lyrics → Настроить → Импорт текста и синхронизация → Вставить текст**. LRC с таймкодами подхватит позицию плеера, если он её передаёт. Иначе введи текущую позицию песни, например `01:25.500`, и нажми **Пуск с позиции**. **Пауза** останавливает ручной отсчёт. После перемотки укажи новую позицию, а кнопка **Авто** вернёт управление системному плееру. Обычные слова листаются стрелками на экране World Lyrics. Вставленный текст используется до смены песни или сброса.

Аудио, cookies, пароли и микрофон не используются. Ошибки сети и отсутствие результата повторяются с интервалом; до 24 найденных текстов остаются в памяти. Все песни гарантировать невозможно: текст или таймкоды могут отсутствовать у источников либо быть недоступны аккаунту. В этом случае отображается статус поиска; слова и время их появления не выдумываются.

Плеер и браузер Яндекс Музыки читаются через ту же системную медиасессию. Когда одновременно играют несколько плееров, мод предпочитает сессию с позицией воспроизведения. При прочих равных приоритет у Яндекс Музыки. Если браузер на Linux передаёт адрес трека, мод использует его точный ID.

Для получения текстов непосредственно из каталога Яндекса открой **World Lyrics → Настроить → Яндекс Музыка**, вставь личный OAuth-токен с доступом к Яндекс Музыке и нажми **Подключить**. Пароль не подходит. Токен скрыт в поле и для диктора, хранится только в текущем запуске Minecraft и не записывается в конфиги/профили. После перезапуска его нужно указать снова. **Отключить** очищает токен. Доступ к конкретным текстам зависит от аккаунта и правил Яндекса; это независимый клиент неофициального API. [Описание протоколов](LYRICS_API_NOTES.md).

Сохранена необязательная работа офлайн: `config/visionmod/lyrics.lrc` или свои строки через `|` в настройках. Надпись — отдельная плоскость в пространстве мира перед игроком. Она плавно следует его движению и повороту, сохраняет положение при Free Look и переключении F5, меняет видимый размер с расстоянием и перекрывается непрозрачными блоками и моделями. Это один объект с читаемыми лицевой и обратной сторонами, без рамки и копии в HUD. Сохранённые раньше позиции HUD для Lyrics больше не меняют это поведение.

## Метка VisionMod у ника

Бирюзовая **V** рядом с ником в мире и в обычном TAB показывает пользователя VisionMod. Переключатель находится во **Внешний вид → Метка VisionMod у ника**; выключение убирает метку и объявление мода другим игрокам. Параметр сохраняется в настройках и профилях.

Для распознавания **других игроков** тот же JAR должен быть установлен на Fabric-сервере с Fabric API. Встроенный сервер одиночной игры также поддерживается. Обмен идёт игровыми пакетами; UUID берётся из серверного соединения. Нет чата, расширения браузера, внешней базы игроков или отдельного сервиса.

На сервере без поддержки обмена видна только собственная метка в TAB: клиент не может достоверно определить чужие моды. Мод продолжает работать, не посылая неизвестные серверу пакеты. Метка — объявление клиента, а не проверка подлинности его JAR; обычным игрокам она не добавляется по догадке. Скрытые ники и серверное оформление сохраняются.

## Остальные функции

FullBright, видимость в воде/лаве, подсветка выбранных открытых руд, фильтр частиц, HUD, редактор прицела, шалькер-подсказки, Trails / Jump Circles / China Hat, локальный питомец, простые JSON-модели, боевые визуальные эффекты, профили и обратимый FPS Boost. JEI и MezzConfig вкладываются в итоговый JAR.

Питомец плавно следует поворотам камеры и высоте игрока с небольшой задержкой. В F5 пример JSON-модели закреплён на спине; возле камеры декоративные модели скрываются. Без музыки и своего текста пустая плашка World Lyrics не появляется.

Часть эффектов остаётся упрощённой реализацией. Camera Streaks не является настоящим Motion Blur; клиентские эффекты копья не меняют серверную механику. [Матрица 35 требований](FEATURE_REQUESTS_2_0_0.md) — исторический план, не подтверждение завершения.

## Сборка и проверки

Java **JDK 21** (нужен `javac`), Gradle **9.7.1**:

```sh
gradle build --no-daemon --max-workers=2
bash tests/run-core.sh
```

JAR: `build/libs/visionmod-2.0.0.jar`. Тесты ядра могут запускаться отдельно от Fabric: скрипт скачивает Gson 2.11.0 из Maven Central и проверяет его опубликованную контрольную сумму. Можно передать `GSON_JAR` с этим артефактом.

Linux-интеграция: `bash tests/run-mpris.sh` (нужны `dbus-next` для Python, `gdbus`, `dbus-run-session`). Проверка запускается на отдельной тестовой D-Bus-шине, не трогая настоящий плеер.

**Проверки 16.11.2026:** Fabric-сборка и запуск Minecraft в CI прошли; 54 переключателя сохраняются, восемь редакторов сняты из настоящего framebuffer и просмотрены. Проверены реальные Alt/мышь/Camera, отпускание/F5/меню/переназначение и анимация хотбара. LRCLIB через рабочий код вернул 58 строк с таймкодами. Windows Media Control ответил на настоящей Windows-машине; Linux MPRIS проверен через отдельную D-Bus-сессию. Локально: 280 core / 283 с MPRIS, ещё 16 проверок источника, 8 HTTP fixture и проверки геометрии. Не проверены живой Spotify с аудио, Sodium/Iris и FPS. Точные SHA: [управление и Lyrics](CONTROLS_LYRICS_QA_RU.md), [визуалы](NATIVE_LYRICS_QA_RU.md).
